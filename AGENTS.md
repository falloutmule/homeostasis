# HOMEOSTASIS repository guide

## Source and artifact authority

- Editable game source is `src/`, with `public/`, `sfhs.project.json`, and `package.json`.
- `dist/index.html` is generated by the pinned SFHS toolchain. Never edit it by hand or commit it as source.
- Root `index.html` is the retained, previous GitHub Pages artifact (`homeostasis-f9724aa9fefe`). It is not editable source and must remain untouched until an Action-based replacement has passed all release gates.
- `one-shot/` records the SFHS Graduation Protocol source lineage and migration plan. The original prototype and its archive are read-only historical inputs.

## Toolchain

This project is an SFHS workspace consumer, pinned by `one-shot/SFHS-PIN.json` to `falloutmule/single-file-html-software@fc8cbd8fc5d1dbb6bf3251d62954e8558e533619`, adapter `pixi-v8`, Node 24+, and pnpm 11.9+.

Run SFHS commands from a checkout of that pinned SFHS repository after staging this repository at `examples/homeostasis`. The CI workflow is the reproducible reference.

## Required checks

Run, in order: `inspect`, `validate`, `check`, `pack`, `verify`, and `node examples/homeostasis/tools/run-browser-proof.mjs`. The browser proof targets Samsung Galaxy S21 Ultra Android Chrome emulation first and desktop Chromium second. Emulation is not physical-device acceptance.

## Release rules

- No runtime external URLs, remotely loaded assets, `eval`, dynamic `Function`, or inline event handlers may be introduced by HOMEOSTASIS-authored code.
- Keep input, fixed-step simulation, and rendering separated; rendering must not persist or mutate simulation state.
- Do not alter gameplay, controls, balance, art direction, or story during repository graduation without a separate approved design decision.
- Do not merge a source release or switch GitHub Pages to Actions until `releases/manifests/release-gate.json` reports a real Samsung Galaxy S21 Ultra / stable Android Chrome PASS for the exact artifact SHA-256.
- Keep current evidence and one immediately previous verified generation. Do not remove evidence carrying a unique physical-device result, unresolved failure, rights record, or release lineage.
